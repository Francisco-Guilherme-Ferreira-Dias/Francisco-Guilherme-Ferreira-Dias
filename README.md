# Oi, eu sou o Guilherme 👋

Sou estudante de **Ciência da Computação na Universidade Federal do Ceará (UFC)** e venho desenvolvendo minhas habilidades em desenvolvimento de software através de projetos práticos.

Gosto de transformar o que aprendo em aplicações reais, explorando desde a construção do back-end e APIs até a integração com interfaces web.

## 🔭 No que estou trabalhando agora

Atualmente estou desenvolvendo o **[GEFIN](https://github.com/Francisco-Guilherme-Ferreira-Dias/GEFIN---Gerenciador-de-Gastos)**, um gerenciador de finanças pessoais que começou como um projeto em C# e vem evoluindo para uma aplicação web **Full Stack**.

O projeto atualmente utiliza **ASP.NET Core, Entity Framework Core, SQLite e Vue.js**, permitindo que eu pratique na mesma aplicação conceitos de back-end, front-end, banco de dados e integração através de APIs REST.

Também continuo desenvolvendo outros projetos acadêmicos e pessoais para explorar diferentes tecnologias e conceitos da Ciência da Computação.
